Bem-vindo ao módulo de fundações do repositório **Dev Journey 2026**. 

Esta pasta documenta a evolução prática do aprendizado, focada em transformar lógicas de programação em código executável, avançando de algoritmos estruturais no terminal para sistemas interativos utilizando **Java Swing**.

---

## 📂 O que você vai encontrar aqui?

Os projetos estão arquitetados para demonstrar a aplicação de regras de negócio integradas a interfaces gráficas (GUI).

### 🏆 Projetos Práticos (Nível 1)
Localizados na pasta `/Projetos-nivel-1`, são sistemas funcionais de maior complexidade:
*   🏦 **Caixa Eletrônico (ATM):** Sistema com validação de saldo e cálculo dinâmico de divisão (e resto) para contagem de cédulas em saques.
*   🏠 **Simulador de Financiamento:** Validador de crédito imobiliário que aplica matemática financeira real (Cálculo de Juros Compostos pela Tabela Price) e regras de aprovação de financiamento.

### 🧩 Fundamentos & Interfaces Gráficas
Na raiz desta pasta, encontram-se os componentes de fundação lógica e visual:
*   **Interatividade Swing:** Projetos com sufixo `*Swing` focados em manipuladores de eventos e painéis (Ex: `CalculadoraIdade`, `IdiomaSistemaSwing`).
*   **Matemática Computacional:** Encapsulamento de cálculos e uso da biblioteca Math (Ex: `EqSegGrau`, `OpSwingMath`, `FatorialSwing`).
*   **Controle de Fluxo:** Domínio de estruturas de repetição e lógicas condicionais (`ExForSwing`, `ExRepita`, `OpTernario`).

## 🚀 Como testar os projetos localmente

1. Faça o clone do repositório principal executando o comando abaixo:
   ```bash
   git clone https://github.com/allisonfsilva/dev-journey-2026.git

2. Abra especificamente a pasta java-básico na sua IDE (recomendado: Apache NetBeans).

3. Para executar as aplicações visuais, clique com o botão direito no arquivo .java desejado na árvore de projetos e selecione Run File (Atalho: Shift + F6).
